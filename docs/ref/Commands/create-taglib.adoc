== create-taglib

=== Description

Creates a Tag Library.

=== Arguments

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Required**

|Tag Library Name
|The name of the Tag Library
|true
|===

=== Flags

[cols="1,2,1"]
|===
|**Name**
|**Description**
|**Type**

|force
|Whether to overwrite existing files
|boolean, default: false
|===

=== Usage

[source,bash]
----
$ grace create-taglib [Tag Library Name]
----
